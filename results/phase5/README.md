# Phase 5 — Availability and adversarial-benign evidence

This directory receives only the validated, compact Phase 5 evidence extracted
from `phase5_final.zip`. Raw session traces, model weights, caches, checkpoints,
and handoffs remain under the Git-ignored `Experiments/phase5/` workspace.

The final bundle is accepted only when `scripts/verify_phase5_results.py` reports
`PHASE 5 RESULTS: PASS`. Until then, this README records the frozen protocol but
does not claim a positive availability result.
