# Phase 2 theory evidence

This directory contains deterministic evidence for the theoretical-surgery
phase. `phase2_theory_audit.json` records the corrected horizon arithmetic and
the exact layerwise continuous-time diagonal-operator norms from the pinned
Mamba-130M audit.

`directional_counterexample.json` and
`directional_counterexample_table.csv` report a seeded suite of 1,000
model-level witnesses. The spectral-collapse control changes the transition
radius and should be detected. The directional family keeps the diagonal
transition exactly fixed and rotates a unit-norm readout away from the retained
state. It therefore tests the boundary of a radius-only completeness claim.

Scope limitation: this construction is not a discrete-token attack and does
not claim that every constructed readout direction is reachable through the
pinned checkpoint's learned token-to-parameter map. Its purpose is to prove
that the spectral-collapse assumption is necessary, not to estimate attack
prevalence.

`anonymity_audit.json` is regenerated by the complete gate and records the
local content/history/PDF checks plus the published anonymous-review URL.

Regenerate both artifacts from the repository root:

```powershell
.\.venv\Scripts\python.exe -m src.eval.phase2_theory_audit --config configs\phase2_theory.yaml
.\.venv\Scripts\python.exe -m src.attacks.directional_counterexample --config configs\phase2_directional.yaml
```
